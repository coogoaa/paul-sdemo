# 光伏系统计算规则 v2.1 草案（参数与公式增补）

本草案在《提案-0914/docs/计算规则_v2.0.md》基础上，补充“补贴抵扣、州别电价、容量门槛吸附、成本差异化”等内容；优先面向 Residential（On-Grid，新建）的大屋顶场景。

---

## 1. 变更摘要（相对 v2.0）
- 新增补贴抵扣：
  - `stc_value = stc_count × stc_price_t`
  - `battery_rebate_value = rebate(state, month, battery_kwh)`
  - `price_net = price_base - stc_value - battery_rebate_value`
- 州别电价参数化：`grid_buy_rate[state, quarter]`、`grid_sell_rate[state, quarter]`
- 电池“门槛吸附”：将计算推荐容量向上吸附至最近的补贴档（如 10/13.5/20kWh）
- 成本差异化系数：屋顶类型/并网相别/品牌系列加价系数
- 大屋顶策略参数：Residential 提高高配方案容量系数上限，DC/AC 比动态范围

---

## 2. 新增/调整参数

### 2.1 补贴相关
- STC：
  - `stc_count`：来自数据 `rec_qty`
  - `stc_price_t`：时间序列参数（按月/季）
  - `stc_value = stc_count × stc_price_t`
- 电池补贴（州/联邦）：
  - 政策映射表：`battery_rebate_table(state, start_month, end_month, min_kwh, pricing_type, rate_per_kwh, fixed_amount, cap_amount, require_vpp, eligible_brands, installer_cert, stack_rule)`
  - 函数：`battery_rebate_value = rebate(state, install_month, battery_kwh)`（见 3.2）

### 2.2 电价参数（州×季度）
- `grid_buy_rate[state, quarter]`
- `grid_sell_rate[state, quarter]`

### 2.3 成本差异化（在 v2.0 成本参数基础上）
- 屋顶类型系数：`roof_coef(Tile=1.05, Colorbond=1.00, Other=1.03)`（示例）
- 并网相别系数：`phase_coef(三相=1.03, 单相=1.00)`
- 品牌/系列系数：`brand_tier_coef(高端=1.05–1.10, 标准=1.00)`

### 2.4 策略相关参数（Residential）
- `plan_d_capacity_factor_max = 0.95`
- `dc_ac_ratio_range_residential = [1.20, 1.33]`
- 电池补贴档位（示例锚点）：`tiers = {9.6, 10, 13.5, 20, 22.4, 25.6}`

---

## 3. 公式增补

### 3.1 价格与成本（在 v2.0 2.4 基础上）
- 成本差异化：
  - `cost_panels' = cost_panels × brand_tier_coef × roof_coef`
  - `cost_inverter' = cost_inverter × phase_coef × brand_tier_coef`
  - `cost_battery' = cost_battery × brand_tier_coef`
  - `cost_install' = cost_install × roof_coef × phase_coef`
  - `total_cost' = cost_panels' + cost_inverter' + cost_battery' + cost_install'`
  - `price_base = total_cost' × (1 + profit_margin_rate)`
- 补贴抵扣：
  - `stc_value = stc_count × stc_price_t`
  - `battery_rebate_value = rebate(state, install_month, battery_kwh)`
  - `price_net = price_base - stc_value - battery_rebate_value`

### 3.2 电池补贴函数（通用定义）
```text
rebate(state, month, capacity_kwh):
  1) 命中 state 与 month 的有效政策；
  2) 若 pricing_type=固定额：返回 fixed_amount；
  3) 若 pricing_type=按kWh：返回 min(capacity_kwh × rate_per_kwh, cap_amount)；
  4) 若 pricing_type=阶梯：按容量段累加（或分档取最大），并受 cap_amount 约束；
  5) 若 capacity_kwh < min_kwh 或不满足资格（VPP/白名单/安装商认证）：返回 0。
```

### 3.3 电池容量“门槛吸附”
- 计算得出 `battery_nominal_kwh` 后：
  - `battery_recommended_kwh = snap_to_tier(battery_nominal_kwh, tiers)`
  - `snap_to_tier(x, tiers)`：将 `x` 向上取至最近档位（例如 `12.7 → 13.5`；`19.1 → 20`）

### 3.4 年度节省与回本（在 v2.0 2.5 基础上）
- 使用州别电价：
  - `annual_savings = annual_self×grid_buy_rate[state, q] + annual_export×grid_sell_rate[state, q]`
- 回本期：
  - 毛价版：`payback_years = price_base / annual_savings`
  - 净价版：`payback_years_net = price_net / annual_savings`（推荐展示）

## 4. 住宅大屋顶策略（口径）
- 容量：10–15kW DC（不超过 `roof_max_power_kw`）
- DC/AC：`1.20–1.33`，按品牌/并网规范选择 8/10/12/15kW 逆变器（单台或多台）
- 电池：优先 9.6/10/13.5/20kWh 档，贴合补贴门槛；在高电价/峰谷差州上探 13.5–20kWh
- 展示：统一展示“毛价→STC→电池补贴→净价→年节省→回本（净价版）”

---

## 5. 适用范围与限制
- 适用：On-Grid、New system；STC 适用上限 `<100kW`（住宅优先）
- 不适用：Off-Grid；未满足政策资格（资质/白名单/VPP 等）
