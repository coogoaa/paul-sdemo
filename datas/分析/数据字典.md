# 数据字典（datas/分析/数据字典.md）

本文档对三张 GD 数据表的主要字段进行说明，并给出合并与派生字段口径。

> 注：某些原始字段含义需以数据提供方口径为准（如 `tdate/mdate/gwtid/pvd_num`），此处先按经验标注为“待确认”。

---

## 1) Panels（面板明细）`greendeal_job_panels_副本.csv`

- 主键：`pvd_id`
- 主要字段：

| 字段 | 含义（初始理解） | 备注 |
|---|---|---|
| pvd_id | 项目/订单唯一 ID | 合并主键 |
| tdate | 日期（待确认） | 例：31/7/2024 |
| mdate | 月份/归属日期（待确认） | 例：1/7/2024 |
| gwtid | 外部关联 ID（待确认） | 例：GWT480813 |
| pvd_num | 外部编号（待确认） | 例：PVD5712258 |
| status | 状态 | 取 Approved 为主 |
| is_oswf | 是否开票/工作流（待确认） | Yes/No |
| claimed_quantity | 申领数量（待确认） | 数值 |
| trade_type | 贸易类型 | 常见“PV STC” |
| install_date | 安装日期 | dd/mm/yyyy |
| connected | 并网状态（文本） | 如 “Connected to an electricity grid without battery storage” |
| rec_qty | STC 数量 | 用于 `stc_value` 计算 |
| deemed_years | STC 年限 | 数值 |
| installation_type_name | 安装类型 | New system 为主 |
| connected_type_name | 并网类型 | On-Grid / Off-Grid |
| is_battery_name | 是否带电池（文本） | Yes/No（文本） |
| complete_unit | 完整单元（待确认） | 数值 |
| property_type | 物业类型 | Residential/Commercial |
| street_number/street_name/street_type | 地址 | - |
| suburb/state/post_code | 地区 | - |
| location_latitude/location_longitude | 坐标 | - |
| roof | 屋顶类型 | Colorbond/Tile/Other |
| class | 分类 | 该表为 “Panels” |
| panel_brand | 面板品牌 | - |
| panel_item | 面板型号 | - |
| watts_per_panel | 单块额定功率 (W) | 数值 |
| number_panels | 面板数量 | 数值 |
| rated_output_kw | 额定输出 (kW) | ≈ 面板数×功率（kW） |
| company_id/company_name | 安装商 | - |

## 4) 合并与派生字段口径

- 合并键：`pvd_id`（三表分别先聚合，再合并到系统级一行）
- 过滤条件：`status=Approved`、`installation_type_name=New system`、`connected_type_name=On-Grid`
- 派生字段：

| 字段 | 计算方式 | 说明 |
|---|---|---|
| pv_dc_kw | `sum(rated_output_kw)` | 同一 `pvd_id` 聚合 |
| pv_ac_kw | `sum(ac_power)` | 同一 `pvd_id` 聚合 |
| dc_ac_ratio | `pv_dc_kw / pv_ac_kw` | - |
| has_battery | `battery_kwh>0` 或 `connected` 含有 “with battery storage” | 二值 |
| battery_kwh | `sum(usable_capacity_kwh)` | - |
| stc_count | `rec_qty` | 来自面板/逆变器数据中的 STC 字段 |
| install_month/quarter/year | 从 `install_date` 解析 | dd/mm/yyyy → YYYY-MM/季/年 |
| segment | Residential/Commercial | 来源 `property_type` 或按容量规则回推 |
| big_roof_flag | 大屋顶标记 | Residential：`pv_dc_kw ≥ 10kW`；Small Commercial：`10–99kW` |

---

## 5) 质量校验建议

- 功率一致性：抽样校验 `sum(number_panels × watts_per_panel/1000)` ≈ `pv_dc_kw`（容差 5–10%）
- STC 一致性：`stc_count` 与估算公式的抽样比对
- 去重：同一地址/同一安装日期/同一安装商的重复订单排查
- 缺失：`install_date/state/post_code/brand/model` 等关键字段缺失情况记录与处理策略

---

## 6) 注意事项与待确认

- `tdate/mdate/gwtid/pvd_num/is_oswf/complete_unit` 等字段需与数据提供方确认准确含义与取值范围；
- `connected` 与 `connected_type_name` 为文本与枚举的两种并网标识，分析以 `connected_type_name` 为准，`connected` 辅助；
- Off-Grid 项目不纳入电池补贴与并网经济性分析范围。
