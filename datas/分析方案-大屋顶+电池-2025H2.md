# 大屋顶 + 电池 补贴与经济性分析方案（2025H2）

本文档用于指导在澳洲当前光伏与电池补贴政策框架下，结合 GD 历史数据，产出面向安装商的“大屋顶 + 电池”的优化推荐，目标是最大化补贴与年度节省，并缩短回本期。涉及的数据与规则如下：

- 数据表：
  - `datas/GD/greendeal_job_panels_副本.csv`
  - `datas/GD/greendeal_job_inverters_副本.csv`
  - `datas/GD/greendeal_job_storage_副本.csv`
- 计算规则基础文档：`提案-0914/docs/计算规则_v2.0.md`

---

## 1. 分析目标与关键问题

- 最优目标：面向大屋顶（Residential 大容量 / 小型商用 < 100kW）+ 电池的推荐，最大化补贴、提升年度节省、优化回本周期。
- 研究重点：聚焦 2025 年、尤其 2025-07（电池补贴发布后）至 2025-12 的结构变化与经济性改善。
- 关键问题：
  - 电池渗透率与容量段在 2025-07 后的变化及对 ROI 的影响？
  - 在 STC 与电池补贴约束下，如何为“大屋顶”确定最优 DC/AC 与电池容量档位？
  - 安装商应优先哪些品牌/容量组合以更易触达补贴门槛并带来更高节省？

---

## 2. 数据合并与派生字段

- 主键与合并：以 `pvd_id` 为主键，在各表先按 `pvd_id` 聚合，再进行一对一合并，避免同一 `pvd_id` 的多机型产生笛卡尔乘积。
- 关键字段（聚合后）：
  - 光伏：`pv_dc_kw = sum(rated_output_kw)`；`pv_ac_kw = sum(ac_power)`；`dc_ac_ratio = pv_dc_kw / pv_ac_kw`
  - 电池：`has_battery`（包含 storage 或 connected 含 “with battery storage”）；`battery_kwh = sum(usable_capacity_kwh)`
  - STC/并网：`stc_count = rec_qty`；`connected_type_name = On-Grid`；`installation_type_name = New system`；`status = Approved`
  - 其他：`state/post_code/roof/property_type/company_name/brand*`、`install_date/tdate/mdate`、`install_month/quarter/year`
- 质量校验：
  - 校验 `sum(number_panels × watts_per_panel/1000)` 与 `pv_dc_kw` 的一致性（容差 5–10%）。
  - 抽样校验 `stc_count` 与估算公式的一致性。

---

## 3. 样本定义与过滤

- 时间：
  - 基线：2024 全年（月度趋势）。
  - 重点：2025-01~06（补贴前）、2025-07~12（补贴后）、2026-01~03（稳态）。
- 条件：`status = Approved`、`installation_type_name = New system`、`connected_type_name = On-Grid`。剔除 Off-Grid。
- 大屋顶定义：
  - Residential 大屋顶：`pv_dc_kw ≥ 10kW`（可做 8kW 敏感性）。
  - 小型商用：`10kW ≤ pv_dc_kw < 100kW`（STC 适用上限），重点 20/30/50/99kW 段。

---

## 4. 政策参数框架（参数化建模）

- SRES / STC：`stc_value = stc_count × stc_price_t`，其中 `stc_price_t` 为时间序列参数（按月/季的市场价区间）。
- 电池补贴（2025-07 后，州/联邦）：
  - 资格（州别、On-Grid、设备/安装商资质、VPP 要求）。
  - 门槛（容量档位如 ≥6/10/13.5/20kWh）、金额结构（固定/按 kWh 阶梯/封顶）。
  - 映射函数：`battery_rebate(state, month, capacity_kwh)`。
- 电价参数：`grid_buy_rate[state, quarter]`、`grid_sell_rate[state, quarter]`。
- 成本参数：沿用 `计算规则_v2.0`，并加入品牌/屋顶类型/三相并网加价系数。

---

## 5. 指标体系与输出

- 结构与规模：`pv_dc_kw`、`pv_ac_kw`、`dc_ac_ratio` 分布（按 Residential/Commercial、state、roof）。
- 品牌 Top-N：面板/逆变器/电池的占比与组合矩阵。
- 电池：
  - 渗透率（Attach Rate）：`has_battery` 比例（按月/州/段）。
  - 容量结构：`battery_kwh` 段（4–6/9–10/13–14/20–30/30+）。
  - 门槛贴合度：满足各补贴“容量门槛”的占比与上探趋势。
- 补贴与净价：
  - `stc_value`、`battery_rebate_value`、`price_net = price_base - stc_value - battery_rebate_value`。
- 经济性：
  - `annual_savings_aud`、`payback_period_years`（附上下浮动区间）。
  - 自用率提升：按是否电池与容量段对比。
- 安装商与地区：
  - 安装商排名（attach rate、门槛匹配度、大屋顶占比、品牌熟练度）。
  - 州/邮编热力：容量与渗透率热点区域。

---

## 6. 事件研究（2025-07）

- 切片：pre（2025Q1–Q2）/ post（2025Q3–Q4）/ stabilized（2026Q1）。
- 方法：前后对比、州间差分中的差分（DiD）、门槛响应（容量门槛附近密度上移）、经济性改善（净价↓、回本期↓）。
- 控制：季节性（对比 2024 同期）、剔除 Off-Grid、处理 tdate/mdate 与 install_date 延迟差。

---

## 7. 安装商推荐策略（大屋顶 + 电池）

- Residential 大屋顶（10–15kW DC；`dc_ac_ratio ≈ 1.2–1.33`；三相优先）：
  - 电池档位优先 9.6/13.5/20kWh，贴合门槛；高电价/峰谷价差州上探 13.5–20kWh。
- 小型商用（20–99kW DC）：
  - STC 最大化：DC 贴近 99kW；配置 25–50kWh+ 电池；并网按规范选多台并联系列。
- 品牌组合优先：
  - 面板：Jinko、LONGi、JA、Risen、REC。
  - 逆变器：GoodWe、Sungrow、Fronius、Huawei、SolarEdge。
  - 电池：Tesla Powerwall、Sungrow SBR、Alpha ESS、BYD（标准容量档）。
- 销售呈现：
  - 报价页展示“毛价 → STC → 电池补贴 → 净价 → 年节省 → 回本期”。
  - 以补贴门槛为档位卖点，提供从 9.6 → 13.5/20kWh 的 ROI 对比图。

## 8. 对《计算规则 v2.0》的优化建议（拟 v2.1）

- 价格模块新增补贴抵扣层：
  - `stc_value = rec_qty × stc_price_t`
  - `battery_rebate_value = rebate(state, month, battery_kwh)`
  - `price_net = price_base - stc_value - battery_rebate_value`
- 州别电价参数化：`grid_buy_rate[state, quarter]`、`grid_sell_rate[state, quarter]`。
- 电池容量“门槛吸附”：将计算推荐容量向上吸附至最近补贴档（10/13.5/20kWh 等）。
- 大屋顶策略：
  - Residential 提高 `plan_d_capacity_factor`（≤0.95）；
  - 小型商用约束 `solar_kw ≤ 99.9kW`，动态 `dc_ac_ratio ∈ [1.1, 1.33]`。
- 成本差异化：按 `roof`（Tile/Colorbond）、三相并网、品牌系列加入加价系数。
- 经济性展示：
  - 同时展示“净价回本期”与“毛价回本期”；
  - 自用率与年节省给出电价/上网电价敏感性区间。
