# 经济效益计算器技术文档

## 1. 概述

本文档详细说明 `roi_calculator.html` 的计算逻辑、参数定义、口径说明和实现细节。

**计算器功能**：
- 年度节省（Annual Savings）
- 回本周期（Payback Period）
- 内部收益率（IRR - Internal Rate of Return）

**支持模式**：
- 净计量（Net Metering）/ 非净计量（Non-Net Metering）
- 电池更换方式：按月计提备用金 / 一次性支付

## 3. 核心计算逻辑

### 3.1 发电量衰减模型

**第 n 年实际发电量 P_n**：

```
P_1 = P × (1 - r')                    // 第1年
P_n = P × (1 - r') × (1 - r'')^(n-1)  // 第n年 (n ≥ 2)
```

**示例**（P=6000, r'=2%, r''=0.5%）：
- 第1年：6000 × 0.98 = 5880 kWh
- 第2年：6000 × 0.98 × 0.995 = 5850.6 kWh
- 第10年：6000 × 0.98 × 0.995^9 = 5621.8 kWh

### 3.2 电量分配

**第 n 年电量分配**：

```
U_n = min(a × P_n, E)           // 自用电量
S_n = max(P_n - U_n, 0)         // 售电量（上网）
D_n = max(E - U_n, 0)           // 购电量（从电网）
```

**关系验证**：
- `U_n + S_n = P_n`（发电量 = 自用 + 售出）
- `U_n + D_n = E`（用电量 = 自用 + 购入）

### 3.3 电费计算

#### 3.3.1 未装光伏的年度电费 k_n

```
A = E × x + 365 × z                    // 基准年度电费
k_n = A × (1 + q)^n                    // 第n年电费（考虑通胀）
```

#### 3.3.2 装光伏后的年度电费 J_n

**模式1：非净计量（Non-Net Metering）**

```
C_n = (D_n × x + 365 × z) × (1 + q)^n  // 购电成本 + 固定费
G_n = S_n × y                           // 售电收入（不随通胀）
J_n = C_n - G_n                         // 净电费
```

**特点**：
- 购电和售电独立计算
- 售电收入固定单价（y 不随通胀）
- 固定日费仍需支付

**模式2：净计量（Net Metering）**

```
能量费用 = max(D_n - S_n, 0) × x × (1 + q)^n
固定日费 = 365 × z × (1 + q)^n
馈网收入 = max(S_n - D_n, 0) × y
J_n = 能量费用 + 固定日费 - 馈网收入
```

**特点**：
- 购电和售电可以抵消
- 只有净购电量（D_n - S_n > 0）才计费
- 净售电量（S_n - D_n > 0）才有收入
- 固定日费仍需支付

### 3.4 年度节省 AS_n

```
AS_n = k_n - J_n
```

**说明**：
- 未考虑货币时间价值（不贴现）
- 直接对比同年度的电费差额

## 4. 回本周期计算

### 4.1 计算原理

**目标**：找到累计现金流首次 ≥ 0 的时间点

**初始状态**：
```
累计现金流 = -H（系统成本）
```

**月度迭代**（最多240个月）：
```
第 m 月所在年份 n = ceil(m / 12)
月度现金流 = AS_n / 12 - 电池月度成本
累计现金流 += 月度现金流

if 累计现金流 ≥ 0:
    回本月数 = m
    回本年数 = m / 12
```

### 4.2 电池成本处理

#### 口径1：按月计提备用金

```
月度备用金 = H_battery / (N_battery × 12)
```

**示例**（H_battery=3000, N_battery=10）：
- 每月扣除：3000 / 120 = $25
- 前120个月持续扣除
- 第121个月起不再扣除

**特点**：
- 平滑现金流
- 提前准备电池更换资金
- 更保守的回本预测

#### 口径2：一次性支付

```
if m == N_battery × 12:
    月度现金流 -= H_battery
```

**示例**（H_battery=3000, N_battery=10）：
- 第120个月一次性扣除 $3000
- 其他月份不扣除

**特点**：
- 符合实际支付时点
- 回本曲线有明显跳变
- 更乐观的前期回本预测

### 4.3 输出格式

```
回本周期 < 1个月：  "立即回本"
回本周期 ≤ 240个月： "X.XX 年（≈ Y 个月）"
回本周期 > 240个月： "大于20年"
```

## 5. IRR 计算

### 5.1 现金流构建

**0-20年现金流序列**：

```
CF_0 = -H                              // 初始投资
CF_n = AS_n - 电池投入_n (n=1..20)    // 年度现金流

其中：
电池投入_n = H_battery  (n == N_battery)
电池投入_n = 0          (n != N_battery)
```

**示例**（H=10000, H_battery=3000, N_battery=10）：
```
CF_0  = -10000
CF_1  = AS_1
CF_2  = AS_2
...
CF_10 = AS_10 - 3000   // 电池更换年
CF_11 = AS_11
...
CF_20 = AS_20
```

### 5.2 IRR 求解

**定义**：使净现值（NPV）为零的折现率 r

```
NPV(r) = Σ(n=0 to 20) CF_n / (1 + r)^n = 0
```

**求解方法**：二分法（Bisection Method）

```javascript
function irr(cfs) {
  let low = -0.99, high = 10.0
  
  // 计算NPV函数
  const npv = (r) => cfs.reduce((sum, cf, i) => 
    sum + cf / Math.pow(1 + r, i), 0)
  
  // 扩展搜索区间（如果需要）
  let fL = npv(low), fH = npv(high)
  while (fL * fH > 0 && expand < 20) {
    high *= 2
    fH = npv(high)
    expand++
  }
  
  // 二分法迭代
  for (let iter = 0; iter < 100; iter++) {
    const mid = (low + high) / 2
    const fM = npv(mid)
    
    if (Math.abs(fM) < 1e-6) return mid
    
    if (fL * fM < 0) {
      high = mid
      fH = fM
    } else {
      low = mid
      fL = fM
    }
  }
  
  return null  // 无解
}
```

**收敛条件**：
- |NPV(r)| < 1e-6
- 最大迭代次数：100次

### 5.3 IRR 解读

| IRR 范围 | 投资评价 | 说明 |
|----------|----------|------|
| IRR < 0% | 亏损 | 20年内无法收回投资 |
| 0% ≤ IRR < 5% | 较低收益 | 勉强回本，收益不理想 |
| 5% ≤ IRR < 10% | 中等收益 | 合理的投资回报 |
| IRR ≥ 10% | 高收益 | 优秀的投资项目 |

## 6. 计算口径对比

### 6.1 净计量 vs 非净计量

| 维度 | 净计量（Net Metering） | 非净计量（Non-Net Metering） |
|------|------------------------|------------------------------|
| **购售电抵消** | 可抵消（净购电量计费） | 独立计算（不可抵消） |
| **适用场景** | 政策支持地区 | 无净计量政策地区 |
| **经济性** | 更优（可抵消购电） | 较差（售电价低于购电价） |
| **计算复杂度** | 中等 | 简单 |
| **公式** | `J_n = max(D_n-S_n,0)×x×infl + 365z×infl - max(S_n-D_n,0)×y` | `J_n = (D_n×x + 365z)×infl - S_n×y` |

**示例对比**（E=5000, P_1=5880, a=60%, x=0.3, y=0.08, z=1, q=3%）：

```
第1年：
U_1 = 3528 kWh
S_1 = 2352 kWh
D_1 = 1472 kWh

非净计量：
  C_1 = (1472×0.3 + 365×1) × 1.03 = $831.05
  G_1 = 2352 × 0.08 = $188.16
  J_1 = $831.05 - $188.16 = $642.89

净计量：
  能量费用 = 0（因为 S_1 > D_1）
  固定日费 = 365 × 1 × 1.03 = $375.95
  馈网收入 = (2352-1472) × 0.08 = $70.40
  J_1 = $0 + $375.95 - $70.40 = $305.55

年度节省差异：
  非净计量：k_1 - $642.89 = $897.11
  净计量：k_1 - $305.55 = $1234.45
  差额：$337.34（净计量更优）
```

### 6.2 电池口径对比

| 维度 | 按月计提 | 一次性支付 |
|------|----------|------------|
| **现金流特征** | 平滑 | 跳变 |
| **回本周期** | 更长（保守） | 更短（乐观） |
| **财务规划** | 提前准备 | 集中支付 |
| **适用场景** | 稳健型投资者 | 激进型投资者 |
| **月度扣除** | `H_battery / (N_battery × 12)` | 第 `N_battery × 12` 月扣除 `H_battery` |

**示例对比**（H=10000, AS_1=1200, H_battery=3000, N_battery=10）：

```
按月计提：
  月度现金流 = 1200/12 - 3000/120 = $100 - $25 = $75
  前120个月累计 = -10000 + 75×120 = -$1000
  回本月数 ≈ 133个月（11.1年）

一次性支付：
  前119个月：月度现金流 = $100
  第120个月：月度现金流 = $100 - $3000 = -$2900
  前119个月累计 = -10000 + 100×119 = $900
  第120个月后 = $900 - $2900 = -$2000
  回本月数 ≈ 140个月（11.7年）
```

## 7. 计算假设与限制

### 7.1 核心假设

1. **时间粒度**：年度计算，月度回本周期采用年度均摊
2. **通胀范围**：仅电价通胀，系统成本和售电价不通胀
3. **衰减模型**：线性衰减，不考虑设备故障
4. **自用率恒定**：a 在20年内保持不变
5. **无其他收益**：不考虑政府补贴、税收优惠等
6. **无维护成本**：除电池更换外，不计其他运维成本
7. **电池更换一次**：仅考虑第 N_battery 年更换一次

### 7.2 边界情况

| 场景 | 处理方式 | 说明 |
|------|----------|------|
| P_n < E | 部分自用，部分购电 | 正常计算 |
| P_n ≥ E | 全部自用，剩余上网 | S_n = P_n - E, D_n = 0 |
| a = 100% | 全部自用，无上网 | S_n = 0 |
| a = 0% | 全部上网，无自用 | U_n = 0, S_n = P_n |
| H_battery = 0 | 无电池更换 | 回本周期不扣电池成本 |
| N_battery > 20 | 20年内不更换 | IRR 不扣电池成本 |

### 7.3 已知限制

1. **不支持动态电价**：无法处理峰谷电价、时段电价
2. **不支持多次电池更换**：仅支持一次更换
3. **不支持贴现率调整**：IRR 计算固定使用内部收益率
4. **不支持月度粒度**：年度节省无法精确到月
5. **不支持系统扩容**：假设系统容量20年不变

## 9. 技术实现

### 9.1 核心函数

```javascript
// 发电量衰减
function pn_year(P, r1, r2, year)

```

### 9.2 数据流

```
用户输入参数
    ↓
点击"计算"按钮
    ↓
读取所有输入值（val函数）
    ↓
计算首年结果（computeYear）→ 年度节省
    ↓
计算回本周期（paybackMonths）→ 回本周期
    ↓
构建现金流序列（1-20年）→ IRR
    ↓
渲染计算过程（3个表格）
    ↓
更新KPI卡片显示
```

### 9.3 性能特征

- **计算复杂度**：O(n)，n=20年
- **IRR求解**：O(100)，最多100次迭代
- **回本周期**：O(240)，最多240个月
- **总计算时间**：< 10ms（现代浏览器）
