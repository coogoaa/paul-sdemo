## 使用场景

### 1. 热力图可视化
```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# 读取数据
df = pd.read_csv('hourly_pivot_project524_customFit_total.csv', index_col=0)

# 绘制热力图
plt.figure(figsize=(12, 8))
sns.heatmap(df, cmap='YlOrRd', annot=False, fmt='.2f')
plt.title('小时发电量热力图 - customFit方案')
plt.xlabel('月份')
plt.ylabel('小时')
plt.tight_layout()
plt.show()
```

### 2. 峰值时段分析
```python
import pandas as pd

df = pd.read_csv('hourly_pivot_project524_customFit_total.csv', index_col=0)

# 找出每月的峰值时段
peak_hours = df.idxmax()
print('每月峰值发电时段:')
print(peak_hours)

# 计算每小时的平均发电量
hourly_avg = df.mean(axis=1)
print('\n每小时平均发电量:')
print(hourly_avg.sort_values(ascending=False).head(10))
```

### 3. 季节性对比
```python
import pandas as pd

df = pd.read_csv('hourly_pivot_project524_customFit_total.csv', index_col=0)

# 定义季节
summer = ['1 月', '2 月', '12 月']
winter = ['6 月', '7 月', '8 月']

# 计算季节平均
summer_avg = df[summer].mean(axis=1)
winter_avg = df[winter].mean(axis=1)

# 绘制对比图
import matplotlib.pyplot as plt
plt.plot(summer_avg.index, summer_avg.values, label='夏季', marker='o')
plt.plot(winter_avg.index, winter_avg.values, label='冬季', marker='s')
plt.xlabel('小时')
plt.ylabel('平均发电量 (kWh)')
plt.legend()
plt.grid(True)
plt.show()
```

### 4. Excel 数据透视表

## 关键发现

### 项目 524 - customFit 方案

#### 日发电模式
- **日出时间**: 约 6-7 时开始发电
- **峰值时段**: 12-14 时
- **日落时间**: 约 18-19 时结束发电
- **有效发电时长**: 约 12-13 小时/天

#### 季节性特征
- **夏季** (1月、2月、12月): 
  - 峰值发电量: 0.8+ kWh/小时
  - 日总发电量: 约 6-7 kWh
  
- **冬季** (6月、7月、8月):
  - 峰值发电量: 0.4 kWh/小时
  - 日总发电量: 约 2-3 kWh
  
- **春秋季** (3-5月、9-11月):
  - 峰值发电量: 0.5-0.7 kWh/小时
  - 日总发电量: 约 4-5 kWh

#### 月度对比
| 月份 | 峰值时段 | 峰值发电量 | 日均总量 |
|------|----------|------------|----------|
| 1月 | 13时 | 0.820 kWh | 6.79 kWh |
| 7月 | 13时 | 0.415 kWh | 2.63 kWh |
| 12月 | 13时 | 0.857 kWh | 7.19 kWh |
