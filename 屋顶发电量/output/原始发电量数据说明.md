# 原始发电量数据说明

## 概述

已导出 4 个原始发电量数据 CSV 文件，包含从 `generationPowerVO` 对象中提取的详细发电量信息。

---

## 1. monthlyHourlyPowerList.csv (2,592 条记录)

### 说明
每月每小时的发电量数据，最细粒度的时间序列数据。

### 字段
- `projectId`: 项目 ID
- `designId`: 设计方案 ID
- `designName`: 设计名称
- `panelIndex`: 面板索引
- `month`: 月份 (1-12)
- `hour`: 小时 (0-23)
- `power`: 发电量 (kWh)

### 数据结构
- 3 个设计方案 × 3 个面板 × 12 个月 × 24 小时 = 2,592 条记录

### 示例数据
```csv
projectId,designId,designName,panelIndex,month,hour,power
524,763,customFit,0,1,0,0
524,763,customFit,0,1,5,0.004334275528
524,763,customFit,0,1,6,0.02075476348
524,763,customFit,0,1,12,0.25783046872
```

### 用途
- 分析每小时发电模式
- 识别峰值发电时段
- 优化储能系统配置
- 负荷匹配分析

## 3. monthlyDailyPowerList.csv (108 条记录)

### 说明
每月的平均每日发电量（不是每天的详细数据，而是该月的日均值）。

### 字段
- `projectId`: 项目 ID
- `designId`: 设计方案 ID
- `designName`: 设计名称
- `panelIndex`: 面板索引
- `month`: 月份 (1-12)
- `avgDailyPower`: 该月平均每日发电量 (kWh/天)

### 数据结构
- 3 个设计方案 × 3 个面板 × 12 个月 = 108 条记录

### 示例数据
```csv
projectId,designId,designName,panelIndex,month,avgDailyPower
524,763,customFit,0,1,2.179754303188
524,763,customFit,0,2,1.8878480227266
524,763,customFit,0,7,0.55724089825294
524,763,customFit,0,12,2.3010816580588
```

### 季节性分析
- **夏季** (1-2月，12月): 平均 2.0+ kWh/天
- **秋季** (3-5月): 平均 1.3 kWh/天
- **冬季** (6-8月): 平均 0.6 kWh/天
- **春季** (9-11月): 平均 1.5 kWh/天

### 用途
- 季节性发电趋势分析
- 月度发电预测
- 电费节省估算

## 数据关系

### 计算验证
```
monthlyPowerList ≈ monthlyDailyPowerList × 该月天数
annualGeneratePower ≈ sum(monthlyPowerList)
monthlyPowerList ≈ sum(monthlyHourlyPowerList[该月所有小时])
```

### 示例验证 (Panel 0, 1月)
- `monthlyDailyPowerList`: 2.18 kWh/天
- 1月天数: 31 天
- 预期月度发电量: 2.18 × 31 ≈ 67.58 kWh
- 实际 `monthlyPowerList`: 67.57 kWh ✓

## 数据来源

### 源文件
- `creat_newsys_preview.json` (项目 524)
  - 3 个设计方案: customFit, mostPopular, maxValue
  - 每个方案 3 个面板位置

### JSON 路径
```
data.designs[].layout (JSON字符串)
  → panelLocationInfos[]
    → generationPowerVO
      → monthlyHourlyPowerList: [[24小时] × 12月]
      → annualGeneratePower: float
      → monthlyDailyPowerList: [12个月的日均值]
      → monthlyPowerList: [12个月的总值]
```

## 使用示例

### Python 分析
```python
import pandas as pd
import matplotlib.pyplot as plt

# 读取月度发电量
monthly = pd.read_csv('monthlyPowerList.csv')

# 按设计方案汇总
summary = monthly.groupby(['designName', 'month'])['power'].sum()

# 绘制月度趋势
for design in ['customFit', 'mostPopular', 'maxValue']:
    data = summary[design]
    plt.plot(range(1, 13), data, label=design, marker='o')

plt.xlabel('月份')
plt.ylabel('发电量 (kWh)')
plt.legend()
plt.title('月度发电量趋势对比')
plt.grid(True)
plt.show()

# 读取每小时数据分析峰值时段
hourly = pd.read_csv('monthlyHourlyPowerList.csv')
peak_hours = hourly.groupby('hour')['power'].mean().sort_values(ascending=False)
print('峰值发电时段:')
print(peak_hours.head(5))
```

### Excel 分析
1. 打开 CSV 文件
2. 创建数据透视表:
   - 行: month
   - 列: designName
   - 值: sum(power)
3. 插入折线图查看趋势

5. **面板索引**: 从 0 开始编号
