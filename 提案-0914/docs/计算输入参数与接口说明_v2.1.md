# 计算输入参数与接口说明 v2.1（新建系统 vs 加装储能）

本文档在《提案-0914/docs/计算规则_v2.0.md》（以下简称 v2.0）基础上，结合《datas/分析/计算规则_v2.1_草案.md》（以下简称 v2.1）与《提案-0914/docs/可配置参数清单.md》，给出当前方案所需的“输入参数清单、参数来源/默认、计算流程与输出字段”。支持两类场景：
- 新建系统（PV + Battery）
- 既有光伏加装储能（Battery-only）

核心策略：
- 铺满屋顶优先（在屋顶潜力与并网规范内，将 DC 做到更高的合理档位）
- 电池“门槛吸附”（在目标自用率基础上向 10/13.5/20/22.4/25.6kWh 档位吸附）

---

## 1. 参数分组与来源

说明：
- 新建系统若未指定 `pv_dc_kw`，则：
  - 若 `prefer_full_roof=true` 且给定 `roof_max_power_kw`，DC 取 min(roof_max_power_kw, 15kW) 且不低于 10–13.2kW 的合理范围；
  - 若未给 `roof_max_power_kw`，可按州别“大屋顶”P90（数据画像得到）作为参考上限。
- 加装储能不改变 PV 容量，需提供现有 PV DC（或以州别中位值估算，仅用于 ROI 粗算）。

## 2. 计算流程（摘要）

### 2.1 新建系统（PV+Battery）
1) 确定 DC/AC：
- 若指定 `pv_dc_kw/pv_ac_kw`，直接使用；
- 否则按 `prefer_full_roof` 与 `roof_max_power_kw` 或州别 P90 推 DC（上限 15kW），再按 `target_dc_ac` 反推 AC 到可用机型（8/10/12/15kW）。

2) 电池容量：
- 若指定 `battery_kwh`，直接使用；
- 否则依据 `annual_generation = pv_dc_kw × yield[state]`、`sc_baseline/sc_target`、`DoD/RTE` 推导名义值并“门槛吸附”（10/13.5/20/...）。

3) 成本与毛价（v2.0 2.4）：
- 面板/逆变器/电池/安装各自成本×加价系数（roof/phase/brand），
- 合计后乘 `(1 + profit_margin_rate)` 得 `price_base`。

4) 补贴抵扣（v2.1 新增）：
- `stc_value = stc_count × stc_price_t`（rec_qty 优先；无则按 `stc_per_kw_fallback × pv_dc`）
- `battery_rebate_value = rebate(state, month, battery_kwh)`（固定/按kWh/上限）
- `price_net = price_base - stc_value - battery_rebate_value`

5) 经济性（v2.0 2.5 扩展）：
- `annual_savings = gen×sc_target×buy + (gen - gen×sc_target)×sell`
- 回本（净）：`payback_years_net = price_net / annual_savings`

### 2.2 加装储能（Battery-only）
1) 电池容量：固定档位 A' 9.6 / B' 13.5 / C' 20.0（或按“门槛吸附”）
2) 成本与毛价：
- `cost_battery = battery_kwh × battery_unit_cost_per_kwh_new`
- `install = battery_only_install_base_cost + battery_kwh × battery_only_install_per_kwh`
- `price_base = (cost_battery + install) × (1 + profit_margin_rate_battery_only)`
3) 补贴与净价：`price_net = price_base - rebate(state, month, battery_kwh)`
4) 经济性“增量”：基准自用率 0.3 → 0.7 的年度节省差额（按州别 buy/sell）
- 回本（净）：`payback_years_net = price_net / annual_savings_uplift`

## 4. 依赖表与口径对齐
- STC：优先使用数据字段 `rec_qty`；无则按 `stc_per_kw_fallback × pv_dc_kw` 估算。
- 电池补贴：州别起止时间、门槛、计价方式与封顶金额需在 `battery_rebate_table` 内提供。
- 买卖电价：按 `(state, quarter)` 映射；如缺失，使用经验默认。
- 年发电量：`yield_per_kw_by_state[state]`；如缺失，使用经验默认。

---

## 5. 错误与兜底
- 关键字段缺失（如 state/month/installation_type）→ 返回参数错误。
- 价格/电价/补贴缺失 → 使用经验默认并在输出中标注 `warnings`。
- 自用率参数异常（sc_target ≤ sc_baseline）→ 自动校正或返回警告。

---

## 6. 与 v2.0 的对应关系
- v2.0 的“屋顶潜力分析/新建方案/储能扩容”仍为基础；v2.1 仅新增：
  - 补贴抵扣层（STC、电池补贴）、州别电价参数化、门槛吸附与成本差异化系数；
  - 双类型（新建/加装）的统一参数接口与输出字段。

> 本说明面向接口与参数层，便于产品与工程对接实现；具体参数默认值请以《datas/分析/参数清单.md》为准。
