### 计算
1. 筛选有效坡面
对3D模型返回的每一个屋顶坡面，执行以下两个条件判断：
- 条件A (面积筛选): 如果 该坡面面积 < 【最小有效面积min_facet_area_m2】，则排除此坡面。
- 条件B (朝向筛选): 如果 该坡面方位角 在 【南向排除方位角下限 azimuth_exclusion_min】和 【南向排除方位角上限 azimuth_exclusion_max】 之间，则排除此坡面。
- 只有同时满足这两个条件（面积够大且朝向非南）的坡面，才会进入下一步计算。

2. - 计算单个有效坡面的最大面板数facet_max_panels
单个有效坡面的最大面板数 = 单个坡面的面积 / 单块面板面积。数值向下取整
facet_max_panels = facet_area_m2 / panel_area_m2

3. - 计算单个有效坡面的最大装机容量facet_max_power_kw
facet_max_power_kw = facet_max_panels * panel_power_kw

4. - 计算屋顶总计最大面板数roof_max_panels
把所有通过筛选的、有效坡面的最大面板数相加
roof_max_panels = sum(facet_max_panels)

5. - 计算屋顶最大装机容量roof_max_power_kw
用总面板数乘以单块板的功率，得出整个屋顶的最大理论光伏系统容量。
roof_max_power_kw = sum (facet_max_power_kw)

### 4.2.3 计算各方案光伏容量和组件
1. - 计算每个方案的光伏容量solar_kw
solar_kw = 屋顶最大装机容量 * 每个方案的容量系数

2. - 计算每个方案的面板数量panel_count，用以在界面展示
panel_count = 当前方案的solar_kw / 预设单块面板功率，向下取整

3. - 计算每个方案的逆变器功率inverter_kw
inverter_kw = 当前方案的光伏容量 / 预设容配比
向上取整至 0.1kw

4. - 年发电量预估annual_generation_kwh
- 由Pvlib计算，通过已计算出的solar_kw、panel_count、inverter_kw 等计算annual_generation_kwh
- 如果Pvlib没有计算结果，则使用`solar_kw * yield_per_kw_per_year`预估
- yield_per_kw_per_year 表示每 kw 光伏系统的年度发电量

2. 计算过程
- 成本计算逻辑：
面板成本 = 面板数量 * 单价
逆变器成本 = 逆变器功率  * 每 kw 逆变器单价
电池成本 = 电池标称容量 * 每 kwh 电池单价
辅材及安装 = 安装基础费 + 方案系统容量 * 每KW 安装费
总成本 = 面板成本 + 逆变器成本 + 电池成本 + 辅材安装成本
基准报价 = 总成本 * （1 + 预设利润率）

- 计算公式
        - `cost_panels = panel_count * panel_unit_cost`
        - `cost_inverter = inverter_kw * inverter_unit_cost_per_kw`
        - `cost_battery = battery_nominal_kwh * battery_unit_cost_per_kwh`
        - `cost_install = install_base_cost + solar_kw * install_cost_per_kw`
        - `total_cost = cost_panels + cost_inverter + cost_battery + cost_install`
        - `price_base = total_cost * profit_margin_rate`

- 报价区间
根据预设的报价浮动范围，在 基准报价 的基础上 上下浮动，用于界面上的展示
        - price_base_floor = 基准报价*（1-浮动范围）
        - price_base_ceiling = 基准报价*（1+浮动范围）
