# 光伏系统计算规则 v2.0

本文档详细描述了光伏系统的完整计算流程，包括屋顶潜力分析、新建光伏方案生成和储能扩容方案生成。

## 1. 屋顶潜力分析

### 1.1 概述
屋顶潜力分析是整个光伏系统设计的基础，通过分析3D建筑模型提供的屋顶坡面数据，计算出屋顶的最大光伏装机潜力。

### 1.2 输入参数

#### 预设参数
| 参数标识 | 参数描述 | 默认值 | 单位 | 备注 |
|---------|---------|--------|------|------|
| panel_area_m2 | 单块面板面积 | 1.9 | m² | 可配置 |
| panel_power_kw | 单块面板功率 | 0.44 | kW | 可配置 |
| azimuth_exclusion_min | 南向排除方位角下限 | 150 | 角度 | 可配置 |
| azimuth_exclusion_max | 南向排除方位角上限 | 210 | 角度 | 可配置 |
| min_facet_area_m2 | 最小有效坡面面积 | 10 | m² | 可配置 |

#### GIS提供参数
| 参数标识 | 参数描述 | 单位 | 备注 |
|---------|---------|------|------|
| facet_azimuth | 单个坡面的方位角 | 角度 | 3D模型提供 |
| facet_area_m2 | 单个坡面的面积 | m² | 3D模型提供 |

### 1.3 计算流程

#### 步骤1：筛选有效坡面
对3D模型返回的每一个屋顶坡面，执行以下筛选条件：

**条件A（面积筛选）：**
```
IF facet_area_m2 < min_facet_area_m2 THEN
    排除此坡面
END IF
```

**条件B（朝向筛选）：**
```
IF azimuth_exclusion_min ≤ facet_azimuth ≤ azimuth_exclusion_max THEN
    排除此坡面
END IF
```

**说明：** 只有同时满足面积够大且朝向非南的坡面，才会进入下一步计算。

#### 步骤2：计算单个有效坡面的最大面板数
```
facet_max_panels = FLOOR(facet_area_m2 / panel_area_m2)
```
**说明：** 使用向下取整确保面板数为整数。

#### 步骤3：计算单个有效坡面的最大装机容量
```
facet_max_power_kw = facet_max_panels × panel_power_kw
```

#### 步骤4：计算屋顶总计最大面板数
```
roof_max_panels = Σ(facet_max_panels)
```
**说明：** 对所有通过筛选的有效坡面的最大面板数求和。

#### 步骤5：计算屋顶最大装机容量
```
roof_max_power_kw = Σ(facet_max_power_kw)
```
**说明：** 整个屋顶的最大理论光伏系统容量。

### 1.4 输出参数
- `facet_max_panels`：单个有效坡面的最大面板数
- `facet_max_power_kw`：单个有效坡面的最大装机容量
- `roof_max_panels`：屋顶总计最大面板数
- `roof_max_power_kw`：屋顶最大装机容量

## 2. 新建光伏方案生成

### 2.1 概述
基于屋顶潜力分析结果，系统并行计算四份独立的光伏方案（A、B、C、D），每个方案具有不同的容量系数和目标自用率，以供用户比较和选择。

### 2.2 输入参数

#### 预设参数
| 参数标识 | 参数描述 | 默认值 | 单位 | 备注 |
|---------|---------|--------|------|------|
| plan_a_capacity_factor | 方案A 容量系数 | 0.3 | - | 可配置 |
| plan_b_capacity_factor | 方案B 容量系数 | 0.5 | - | 可配置 |
| plan_c_capacity_factor | 方案C 容量系数 | 0.8 | - | 可配置 |
| plan_d_capacity_factor | 方案D 容量系数 | 0.9 | - | 可配置 |
| dc_ac_ratio | 容配比 (DC/AC) | 1.33 | - | 可配置 |
| baseline_self_consumption_rate | 基线自用率 (无电池) | 0.3 | - | 可配置 |
| battery_dod | 电池放电深度 DoD | 0.9 | - | 可配置 |
| battery_rte | 电池往返效率 RTE | 0.95 | - | 可配置 |
| yield_per_kw_per_year | 每kW年发电量 | 1526 | kWh/kW/yr | pvlib无结果时使用 |
| plan_a_target_sc_rate | 方案A 目标自用率 | 0.3 | - | 可配置 |
| plan_b_target_sc_rate | 方案B 目标自用率 | 0.5 | - | 可配置 |
| plan_c_target_sc_rate | 方案C 目标自用率 | 0.7 | - | 可配置 |
| plan_d_target_sc_rate | 方案D 目标自用率 | 0.9 | - | 可配置 |

#### 上游计算参数
| 参数标识 | 参数描述 | 单位 | 来源 |
|---------|---------|------|------|
| roof_max_power_kw | 屋顶最大可装机容量 | kW | 屋顶潜力分析 |

### 2.3 计算流程

#### 步骤1：计算各方案光伏容量
```
solar_kw = roof_max_power_kw × capacity_factor
```
其中 `capacity_factor` 为对应方案的容量系数（plan_a/b/c/d_capacity_factor）

#### 步骤2：计算各方案面板数量
```
panel_count = FLOOR(solar_kw / panel_power_kw)
```
**说明：** 用于界面展示，向下取整确保为整数。

#### 步骤3：计算各方案逆变器功率
```
inverter_kw = CEILING_TO_0.1(solar_kw / dc_ac_ratio)
```
**说明：** 向上取整至0.1kW。

#### 步骤4：年发电量预估
**优先使用pvlib计算：**
```
annual_generation_pvlib_kwh = pvlib_calculate(solar_kw, panel_count, inverter_kw, ...)
```

**兜底计算（当pvlib无结果时）：**
```
annual_generation_kwh = solar_kw × yield_per_kw_per_year
```

#### 步骤5：计算电池容量需求

**计算每日需转移能量：**
```
daily_energy_to_shift_kwh = (annual_generation_kwh / 365) × (target_sc_rate - baseline_self_consumption_rate)
```

**计算推荐电池标称容量：**
```
IF daily_energy_to_shift_kwh > 0 THEN
    battery_nominal_kwh = ROUND(daily_energy_to_shift_kwh / (battery_dod × battery_rte), 2)
ELSE
    battery_nominal_kwh = 0
END IF
```

### 2.4 成本与报价计算

#### 预设参数
| 参数标识 | 参数描述 | 默认值 | 单位 | 备注 |
|---------|---------|--------|------|------|
| panel_unit_cost | 单块面板成本 | 350 | AUD/块 | 可配置 |
| inverter_unit_cost_per_kw | 每kW逆变器成本 | 250 | AUD/kW | 可配置 |
| battery_unit_cost_per_kwh_new | 电池每kWh成本 (新建) | 200 | AUD/kWh | 可配置 |
| install_base_cost | 安装基础费用 | 1000 | AUD | 可配置 |
| install_cost_per_kw | 安装每kW费用 | 150 | AUD/kW | 可配置 |
| profit_margin_rate | 利润率 | 0.1 | - | 可配置 |
| price_float_range | 报价浮动范围 | 0.05 | - | 可配置 |

#### 计算公式
**成本计算：**
```
cost_panels = panel_count × panel_unit_cost
cost_inverter = inverter_kw × inverter_unit_cost_per_kw
cost_battery = battery_nominal_kwh × battery_unit_cost_per_kwh_new
cost_install = install_base_cost + solar_kw × install_cost_per_kw
total_cost = cost_panels + cost_inverter + cost_battery + cost_install
```

**报价计算：**
```
price_base = total_cost × (1 + profit_margin_rate)
price_base_floor = price_base × (1 - price_float_range)
price_base_ceiling = price_base × (1 + price_float_range)
```

### 2.5 经济效益计算

#### 预设参数
| 参数标识 | 参数描述 | 默认值 | 单位 | 备注 |
|---------|---------|--------|------|------|
| grid_buy_rate | 购电价 | 0.3 | AUD/kWh | 可配置 |
| grid_sell_rate | 售电/馈网价 | 0.07 | AUD/kWh | 可配置 |
| annual_profit_range | 年度节省浮动展示区间 | 0.05 | - | 可配置 |
| sc_rate_display_range | 自用率展示浮动范围 | 0.05 | - | 可配置 |

#### 计算公式

**年度自用电量：**
```
annual_self_consumption_kwh = annual_generation_kwh × target_sc_rate
```

**年度上网电量：**
```
annual_grid_export_kwh = annual_generation_kwh - annual_self_consumption_kwh
```

**年度节省：**
```
annual_savings_aud = (annual_self_consumption_kwh × grid_buy_rate) + (annual_grid_export_kwh × grid_sell_rate)
```

**年度节省浮动展示：**
```
annual_savings_floor = annual_savings_aud × (1 - annual_profit_range)
annual_savings_ceiling = annual_savings_aud × (1 + annual_profit_range)
```

**回本周期：**
```
payback_period_years = price_base / annual_savings_aud
payback_period_floor = price_base / annual_savings_ceiling
payback_period_ceiling = price_base / annual_savings_floor
```

**自用率区间展示：**
```
sc_rate_display_floor = target_sc_rate × (1 - sc_rate_display_range)
sc_rate_display_ceiling = target_sc_rate × (1 + sc_rate_display_range)
```

### 2.6 输出参数
- `solar_kw`：光伏容量
- `panel_count`：面板数量
- `inverter_kw`：逆变器功率
- `battery_nominal_kwh`：推荐电池容量
- `price_base`：基准报价
- `annual_savings_aud`：年度节省
- `payback_period_years`：回本周期

## 3. 储能扩容方案生成

### 3.1 概述
针对已安装光伏系统但未配置储能的用户，推荐四种不同容量的电池扩容方案。假设用户已使用屋顶理论发电潜力的70%，当前自用率为30%。

### 3.2 输入参数

#### 预设参数
| 参数标识 | 参数描述 | 默认值 | 单位 | 备注 |
|---------|---------|--------|------|------|
| retrofit_plan_a_kwh | Retrofit 方案A 电池容量 | 5 | kWh | 可配置 |
| retrofit_plan_b_kwh | Retrofit 方案B 电池容量 | 10 | kWh | 可配置 |
| retrofit_plan_c_kwh | Retrofit 方案C 电池容量 | 13.5 | kWh | 可配置 |
| retrofit_plan_d_kwh | Retrofit 方案D 电池容量 | 20 | kWh | 可配置 |
| battery_unit_cost_per_kwh_retrofit | 电池成本 (储能升级) | 500 | AUD/kWh | 可配置 |
| battery_install_base_cost | 电池安装基础费 | 500 | AUD | 可配置 |
| battery_install_cost_per_kwh | 电池安装每kWh费用 | 50 | AUD/kWh | 可配置 |
| battery_profit_margin_rate | 电池扩容利润率 | 0.1 | - | 可配置 |
| battery_price_range_percent | 电池扩容报价浮动范围 | 0.05 | - | 可配置 |
| rooftop_use_factor | 屋顶理论最大容量使用系数 | 0.7 | - | 可配置 |
| annual_effective_days | 电池年度有效利用天数 | 300 | 天 | 可配置 |
| battery_annual_profit_range | 年度节省金额浮动比例 | 0.05 | - | 可配置 |
| existing_sc_rate | 已有系统基线自用率 | 0.3 | - | 可配置 |
| existing_solar_annual_gen_kwh | 已有光伏系统年发电量理论最大值 | 8000 | kWh/yr | 可配置 |
| sc_rate_lower_limit | 自用率展示下限系数 | 0.9 | - | 可配置 |

### 3.3 成本与报价计算

#### 计算公式

**电池扩容成本：**
```
retrofit_battery_cost = (selected_battery_kwh × battery_unit_cost_per_kwh_retrofit) + 
                        battery_install_base_cost + 
                        (selected_battery_kwh × battery_install_cost_per_kwh)
```

**报价基准值：**
```
retrofit_price_base = retrofit_battery_cost × (1 + battery_profit_margin_rate)
```

**报价浮动范围：**
```
retrofit_price_floor = retrofit_price_base × (1 - battery_price_range_percent)
retrofit_price_ceiling = retrofit_price_base × (1 + battery_price_range_percent)
```

### 3.4 经济效益计算

#### 计算公式

**电池理论每日有效放电电量：**
```
daily_effective_discharge_kwh = selected_battery_kwh × battery_dod × battery_rte
```

**年度节省金额：**
```
retrofit_annual_savings = daily_effective_discharge_kwh × (grid_buy_rate - grid_sell_rate) × annual_effective_days
```

**年度节省金额浮动展示：**
```
retrofit_savings_floor = retrofit_annual_savings × (1 - battery_annual_profit_range)
retrofit_savings_ceiling = retrofit_annual_savings × (1 + battery_annual_profit_range)
```

**回本周期：**
```
retrofit_payback_years = retrofit_price_base / retrofit_annual_savings
retrofit_payback_floor = retrofit_price_base / retrofit_savings_ceiling
retrofit_payback_ceiling = retrofit_price_base / retrofit_savings_floor
```

### 3.5 自用率提升计算

#### 计算公式

**新增自用电量：**
```
additional_self_consumption_kwh = MIN(
    selected_battery_kwh × battery_dod × battery_rte × annual_effective_days,
    roof_max_power_kw × rooftop_use_factor × yield_per_kw_per_year
)
```

**自用率提升：**
```
sc_rate_improvement = additional_self_consumption_kwh / (existing_solar_annual_gen_kwh × rooftop_use_factor)
```

**加装后自用率：**
```
retrofit_final_sc_rate = MIN(1, existing_sc_rate + sc_rate_improvement)
```

**自用率区间展示：**
```
retrofit_sc_display_floor = retrofit_final_sc_rate × sc_rate_lower_limit
retrofit_sc_display_ceiling = retrofit_final_sc_rate
```

### 3.6 输出参数
- `retrofit_price_base`：报价基准值
- `retrofit_annual_savings`：年度节省金额
- `retrofit_payback_years`：回本周期
- `retrofit_final_sc_rate`：加装后自用率

## 4. 计算流程总览

### 4.1 整体流程图
```
输入：3D建筑模型数据
    ↓
屋顶潜力分析
    ↓
roof_max_power_kw
    ↓
┌─────────────────┬─────────────────┐
│   新建光伏方案    │   储能扩容方案    │
│   (4个方案)      │   (4个方案)      │
└─────────────────┴─────────────────┘
    ↓                    ↓
成本报价计算          成本报价计算
    ↓                    ↓
经济效益分析          经济效益分析
    ↓                    ↓
输出：完整方案报告    输出：扩容方案报告
```

### 4.2 关键约束条件
1. **面积约束**：`facet_area_m2 ≥ min_facet_area_m2`
2. **朝向约束**：`facet_azimuth ∉ [azimuth_exclusion_min, azimuth_exclusion_max]`
3. **容量约束**：`solar_kw ≤ roof_max_power_kw`
4. **自用率约束**：`sc_rate ≤ 1.0`
5. **电池容量约束**：`battery_nominal_kwh ≥ 0`

### 4.3 数据精度要求
- 面板数量：整数
- 功率值：保留2位小数
- 金额：保留2位小数
- 比例：保留3位小数
- 年份：保留2位小数

## 5. 参数配置指南

### 5.1 核心参数调整建议
1. **容量系数**：根据用户需求层次调整
2. **电价参数**：根据当地电力市场实时调整
3. **设备成本**：根据供应商报价定期更新
4. **技术参数**：根据设备规格书设定

### 5.2 参数验证规则
- 所有比例参数：0 ≤ value ≤ 1
- 所有成本参数：value > 0
- 容配比：1.0 ≤ dc_ac_ratio ≤ 2.0
- 电池DoD：0.8 ≤ battery_dod ≤ 0.95

### 5.3 异常处理
- pvlib计算失败时自动切换到兜底计算
- 除零保护：分母为0时返回默认值
- 数值溢出保护：超出合理范围时使用边界值
