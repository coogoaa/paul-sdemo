# 🚀 快速启动指南

## 第一步：安装依赖

在 PVGIS 目录下运行：

```bash
npm install
```

这将安装以下依赖：
- `express` - Web 服务器框架
- `axios` - HTTP 客户端

## 第二步：启动服务器

```bash
npm start
```

你将看到以下输出：

```
🚀 PVGIS 代理服务器运行在 http://localhost:3001
📄 打开浏览器访问: http://localhost:3001/pvgis_simulator.html
```

## 第三步：打开浏览器

访问 `http://localhost:3001/pvgis_simulator.html`

## 使用示例

### 测试 1：北京的系统性能

1. 点击"填充示例（北京）"按钮
   - 纬度：39.9
   - 经度：116.4

2. 保持默认系统参数：
   - 峰值功率：1 kWp
   - 系统损耗：14%
   - 倾角：35°
   - 方位角：0°（正南）

3. 点击"计算"

**预期结果**：
- 年度发电量：约 1,200-1,400 kWh
- 月度发电量柱状图
- 夏季发电量高于冬季

### 测试 2：小时序列分析

1. 切换到"小时序列" Tab
2. 使用相同的北京坐标（39.9, 116.4）
3. 保持默认参数（倾角 0°，方位角 0°）
4. 点击"计算"

**预期结果**：
- 全年 8760 小时的辐照数据
- 折线图显示日夜变化规律
- 夏季辐照强度高于冬季

### 测试 3：地平线剖面

1. 切换到"地平线" Tab
2. 使用相同的北京坐标（39.9, 116.4）
3. 点击"计算"

**预期结果**：
- 360° 方位角的地平线高度角数据
- 极坐标图显示地平线轮廓

## 常见问题

### Q1: 安装依赖时报错？

**解决方案**：
```bash
# 清除缓存
npm cache clean --force

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### Q2: 启动服务器时端口被占用？

**错误信息**：`Error: listen EADDRINUSE: address already in use :::3001`

**解决方案**：
修改 `proxy-server.js` 中的端口号：
```javascript
const PORT = 3002; // 改为其他端口
```

### Q3: 计算时报错 "PVGIS API 错误"？

**可能原因**：
1. 网络连接问题
2. PVGIS 服务暂时不可用
3. 参数超出有效范围

**解决方案**：
1. 检查网络连接
2. 稍后重试
3. 确认纬度（-90~90）和经度（-180~180）在有效范围内

### Q4: 图表不显示？

**可能原因**：Chart.js CDN 加载失败

**解决方案**：
检查浏览器控制台是否有错误，确保网络可以访问 `cdn.jsdelivr.net`

## 开发模式

使用 nodemon 实现自动重启（代码修改后自动重启服务器）：

```bash
npm run dev
```

## 性能优化

### 缓存机制

相同参数的请求会命中缓存（1小时有效期），大幅提升响应速度：

```
📡 收到请求: PVcalc { lat: 39.9, lon: 116.4, ... }
✅ 命中缓存
```

### 速率限制

服务器自动限制请求速率（~30 次/秒），避免触发 PVGIS API 限制。
