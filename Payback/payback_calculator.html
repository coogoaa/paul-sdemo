核心计算公式 (基于Java逻辑)

月发电量:
ymP = 基础月发电量 × (1 - 年度功率衰减率)^(年份-1)
自用电量:
ymU = min(ymP × 自用比例, 月用电量) [有电池时]
上网电量:
ymS = ymP - ymU
需购买电量:
ymD = max(月用电量 - ymU, 0)
电池费用摊销 (新逻辑):
battery10YearAvgFee = 电池总费用 / 120个月
batteryAmortizationCum += battery10YearAvgFee (每月累加)
最终价格:
finalPrice = 初始系统价格 + batteryAmortizationCum
累计差额:
cumulativeDiff = buyAfterCum + finalPrice - buyBeforeCum
回本条件:
当 cumulativeDiff ≤ 0 时达到回本点
