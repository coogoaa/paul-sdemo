# 太阳能投资回本期计算器 - 使用说明

## 🎯 功能特点

这是一个**纯HTML单文件应用**，完全按照 `payback.py` 的逻辑实现，具有以下特点：

- ✅ **零依赖**: 无需安装任何软件或库
- ✅ **即开即用**: 双击HTML文件即可在浏览器中运行
- ✅ **完整功能**: 包含参数配置、计算过程、结果可视化
- ✅ **响应式设计**: 支持手机、平板、电脑等不同设备

## 🚀 快速开始

### 方法1: 直接打开文件
1. 找到 `payback_calculator.html` 文件
2. 双击文件，会在默认浏览器中打开
3. 开始使用计算器

### 方法2: 通过浏览器打开
1. 打开任意浏览器（Chrome、Firefox、Safari等）
2. 按 `Ctrl+O` (Windows) 或 `Cmd+O` (Mac)
3. 选择 `payback_calculator.html` 文件
4. 点击打开

## 📈 核心计算逻辑

### 主要公式
```
月发电量: ymP = 基础月发电量 × (1 - 年度功率衰减率)^(年份-1)
自用电量: ymU = min(ymP × 自用比例, 月用电量) [有电池时]
上网电量: ymS = ymP - ymU
需购买电量: ymD = max(月用电量 - ymU, 0)
累计差额: cumulativeDiff = buyAfterCum + finalPrice - buyBeforeCum
```

### 回本判断
当 `累计差额 ≤ 0` 时达到回本点
